# 坦克大战 · Tank Battle

一款使用原生 **HTML5 Canvas + JavaScript** 编写的经典坦克大战（Battle City）网页游戏，单文件即可运行，无需任何依赖。

## 🎮 试玩

- **在线体验**：https://zzz-td.github.io/tank-battle/
- **本地运行**：直接用浏览器打开 `index.html` 即可。

## 🕹️ 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 `方向键` |
| 射击 | `空格` / `J` / `X` |
| 暂停 / 继续 | `P` 或 `Esc` |
| 静音 | `M` |
| 开始 / 重新开始 | `回车` 或点击按钮 |

> 移动端（触屏）会自动显示虚拟方向键与 FIRE 按钮。

## ✨ 玩法特性

- 🎯 **经典玩法**：保卫基地老鹰，消灭全部敌军即可过关
- 🧱 **多样地形**：砖墙（可摧毁）、钢墙、河流（挡坦克不挡子弹）、草丛（隐藏坦克）
- 🤖 **四种敌人**：普通、快速、重火力、装甲（需两发）
- 💎 **随机道具**：火力升级 ⭐、护盾 🛡、额外生命 +1、全屏炸弹 💥
- 📈 **无限关卡**：越往后敌军越多、越强，地图循环并逐步加压
- 🔊 **复古音效**：基于 Web Audio API 实时合成，无外部音频文件

## 🛠️ 技术实现

- 纯原生 HTML / CSS / JavaScript，零依赖、零构建
- Canvas 2D 绘制所有图形（坦克、地形、特效均为矢量绘制，无图片资源）
- 关卡地图采用「半张镜像」生成，保证左右对称
- 60 FPS 游戏循环，基于时间步长（dt）保证不同刷新率下速度一致

## 📦 部署到 GitHub Pages

1. 仓库 → **Settings** → **Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后稍等片刻，即可通过 `https://zzz-td.github.io/tank-battle/` 访问
